# 가로 연표 TOC 설계

2026-06-05 · 브레인스토밍 확정안

## 목적

타임라인 페이지 최상단에 가로 연표를 두어 전체 여정을 한눈에 보여주고, 스크롤 중에는
얇은 눈금 진행바로 축소되어 TOC(점프 내비게이션) + 읽기 위치 표시를 겸한다.

## 확정 결정

| 항목 | 결정 |
|---|---|
| 배치 | 최상단 풀 연표(비 sticky) + 풀 연표가 뷰포트를 벗어나면 헤더 아래 가는 눈금(~20px)만 sticky. 눈금 호버 시 라벨까지 펼침. 헤더는 기존 sticky 유지 |
| 축 방향 | 역순: 왼쪽=현재, 오른쪽=2021.08(연합뉴스). 스크롤(최신→과거)·읽기·진행바 방향 일치 |
| 라벨 위계 | 4층: ① AI 주요(맨 위 상시) ② 어필 featured(축 위) ③ 경력(축 아래 1줄, 진한 라벨) ④ 프로젝트·교육(축 아래 2줄, 연한 작은 라벨) |
| AI 상시 라벨 | ChatGPT 출시(2022.11, LLM 대중화), Claude Code 출시(2025.05, 에이전틱 코딩) 2건. 나머지 마일스톤 4건은 호버 눈금 |
| 어필 라벨 | TappyType("iOS · 진행 중"), bodycodi("레거시 공존 설계") 2건. 한정어는 출처가 아닌 내용을 적는다(채용 과제 출처는 본문 태그가 고지) |
| 시작연도 | 라벨에 연도 표기 없음 |
| 연도 그리드 | 없음 |
| 데스크톱/모바일 | 데스크톱: 모든 마커 라벨 노출(아래 2줄 구조로 충돌 회피). 모바일: 경력+어필 라벨만, 나머지는 점 탭 시 표시. sticky 눈금은 모바일에서 펼침 없이 진행바+점만 |
| 프로그레스 | 시점 매핑: 화면 상단에 걸린 타임라인 항목의 날짜 → 축 좌표가 커서 위치, 현재(왼쪽)부터 그 좌표까지 채움. 단순 스크롤 비율 아님 |
| 플로팅 버튼 | 기존 FloatingButtonGroup 변경 없음 |

### 어필 라벨 선정 근거

두 자리는 폭과 깊이를 하나씩 커버한다.

- TappyType: 기술 폭 — 유일한 네이티브 iOS, 직접 브랜딩·사전 마케팅, 진행 중
- bodycodi: 설계 깊이 — 레거시(JSP) 공존 제약을 직접 조사·정의한 설계 사고의 증거
- 차점 formkit-react는 데스크톱 아래 라벨 줄에 상시 노출되므로 어필층 미선정으로 잃는 것 없음

## 컴포넌트·데이터 구조

- `src/components/sections/TimelineToc.tsx` 신규. 풀 스트립과 sticky 눈금을 한 컴포넌트의
  두 모드로 구현(내부 상태 또는 `variant: 'full' | 'ruler'`)
- 타임라인 데이터 빌더 추출: `PersonalSection` 내부의 timeline 조립 로직
  (careers + extras + galleryItems + LLM_MILESTONES 병합·정렬)을 공유 모듈로 분리해
  본문과 TOC가 동일 데이터를 사용
- 데이터 플래그:
  - `galleryItems`: `featured?: { sublabel: string }` — TappyType, bodycodi
  - `LLM_MILESTONES`: `major?: boolean` — ChatGPT, Claude Code 항목
- 좌표 계산: `pos = (현재월 − 항목월) / (현재월 − 2021.08)` 월 단위 환산, 왼쪽=0%.
  '현재'는 렌더 시점의 연·월(월 단위 앵커이므로 빌드/클라이언트 불일치는 월 경계 순간에만 발생)

## 동작

- 점프: 마커 클릭 → 본문 타임라인 해당 항목으로 스크롤. 각 타임라인 항목에 anchor id 부여
- sticky 전환: 풀 스트립에 IntersectionObserver를 걸어 뷰포트 이탈 시 sticky 눈금 표시
- 프로그레스: IntersectionObserver로 화면 상단에 걸린 항목 감지 → 해당 항목의 축 좌표로
  커서 이동, 왼쪽(현재)부터 채움
- 호버 펼침(데스크톱): sticky 눈금 호버 시 높이 전환으로 라벨층까지 표시

## 접근성

- `<nav aria-label="연표 목차">`, 마커는 키보드 포커스 가능한 링크(`<a href="#anchor">`)
- 호버 전용 정보(보조 AI 눈금, 모바일 숨김 라벨)는 본문에 동일 정보가 존재하므로 보조 수단
